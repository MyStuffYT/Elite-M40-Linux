# Elite-M40-Linux
This is supposed to change your mouse settings for the Spirit of Gamer Elite M40 in Linux.

# Features
Change colors.
Colors you can change to:
Wave 0% Speed
Wave 25% Speed
Wave 50% Speed
Off
